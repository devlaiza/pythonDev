### 📌 Sobre o Repositório

Este espaço reúne meus códigos, desafios de lógica de programação, exercícios práticos e pequenos projetos desenvolvidos com **Python**. O objetivo é consolidar fundamentos da linguagem, estrutura de dados e resolução de problemas.

---

### 🛠️ Conteúdos e Tópicos Estudados

- ⚙️ **Fundamentos:** Variáveis, tipos de dados, operadores e entrada/saída de dados.
- 🔀 **Estruturas Condicionais:** `if`, `elif`, `else`.
- 🔄 **Estruturas de Repetição:** Laços `for` e `while`.
- 📦 **Estruturas de Dados:** Listas, tuplas, dicionários e conjuntos.
- 🧩 **Modularização:** Criação e uso de funções.
